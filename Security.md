# Security & Responsible Use

This repository contains documentation from an authorized **TryHackMe** training environment.

## Intended Use

The material is intended for:

- cybersecurity education
- CTF and lab practice
- defensive understanding of common web and Linux weaknesses
- portfolio documentation

## Scope

The commands, endpoints, credentials, and addresses described here refer to a temporary training target or have been intentionally generalized/redacted.

## Reporting

The vulnerabilities discussed are examples of lab weaknesses. In a real environment, report findings through the organization's authorized security or vulnerability-disclosure process.

## Sensitive Data

Challenge flags and selected secrets are redacted from screenshots and documentation to avoid unnecessary disclosure and to keep the repository focused on methodology rather than answer sharing.
